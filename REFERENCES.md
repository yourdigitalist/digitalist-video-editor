# Reference repositories

Cloned under `references/` (symlink; not committed). Dependencies checked: Node.js 22+, Git, FFmpeg.

| Repository | Purpose |
| --- | --- |
| **PDoomVideo** | Full Claude Opus music-video project — storyboard, animation guide, and headless render patterns for agent-made films. |
| **ClaudeAnimationBase** | Starter kit for p5.js / p5.brush character animation with storyboard-first agent workflow and `render.mjs`. |
| **claude-animation-skill** | Hand-drawn 2D JS animation skill — detail bible, character rigs, sheet/strip/verify harness, ffmpeg export. |
| **hyperframes** | Open-source AI video editor: write HTML, render video; agent CLI, registry blocks, frame checks (cloned with `GIT_LFS_SKIP_SMUDGE=1`). |
| **Battle-of-Austerlitz-Film** | Long-form WebGL documentary film — beat-timed narration, deterministic frame functions, chunked Chromium→ffmpeg render. |
| **awesome-ai-motion** | Curated gallery of AI motion-graphics references and covers for creative direction. |
| **awesome-opus-5-5-videos** | Field guide to Claude-made videos (prompts, benchmarks, techniques across Remotion, Three.js, Blender, etc.). |
