# Digitalist Video Editor

Multi-brand motion graphics dashboard for Cursor. Create a video, attach a brand design system + Google Drive assets, pick motion blocks, then hit **Generate video**.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3847](http://localhost:3847).

## Docs

- `REFERENCES.md` — cloned reference repositories (local)
- `SKILLS.md` — Cursor-adapted skills
- `examples/brands/fungal-dreams/` — sample design system pack
